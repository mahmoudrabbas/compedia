## Project name: Compedia web service
### Features
- public home showing all posts
- adding posts
- login
- signup
- validation
- database migration
- auditing
- caching
- logging
- sanitizing
- unit testing


### API
- home api
  -  http://localhost:8080/
- users apis
  - http://localhost:8080/api/v1/users (GET)
  - http://localhost:8080/api/v1/users/{id} (GET)
  - http://localhost:8080/api/v1/users (Post)
  - http://localhost:8080/api/v1/users (UPDATE)
  - http://localhost:8080/api/v1/users/{id} (DELETE)
- auth api
  - http://localhost:8080/api/auth/sign-in (POST)
  - http://localhost:8080/api/auth/sign-up (POST)
- posts api
  - http://localhost:8080/api/v1/posts (GET)
  - http://localhost:8080/api/v1/posts/{id} (GET)
  - http://localhost:8080/api/v1/posts (POST)
  - http://localhost:8080/api/v1/posts (UPDATE)
  - http://localhost:8080/api/v1/posts/{id} (DELETE)
